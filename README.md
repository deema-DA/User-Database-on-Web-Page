# User-Database-on-Web-Page

# Description
A simple web page to add users and display them in a table, with the ability to toggle each user's status (0 or 1) instantly on the page.

# Features
Add New User: Single-line form to input name and age.

Display Users: Table showing ID, Name, Age, and Status.

Toggle Status: Button for each row to switch the status without reloading the page.

Data Storage: Records stored in a MySQL database.

# Technologies Used
HTML / CSS: Page structure and styling.

JavaScript (AJAX): Update status instantly.

PHP: Handle database operations for inserting and updating data.

MySQL: Store user records and XAMPP
